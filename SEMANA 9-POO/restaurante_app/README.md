## 📌 Descripción del Sistema
El proyecto `restaurante_app` es un sistema interactivo por consola diseñado en Python aplicando el paradigma de la Programación Orientada a Objetos (POO). Su objetivo principal en la Semana 9 es la administración organizada de colecciones de objetos (`Producto` y `Usuario`) mediante la incorporación de estructuras de datos nativas de Python, garantizando un diseño modular, desacoplado y robusto.
